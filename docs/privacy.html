Privacy Policy

Novel Reader: VN–EN Bilingual — Last updated: 2026-05-21

Overview

Novel Reader: VN–EN Bilingual is a Chrome extension for reading Vietnamese web novels with bilingual text-to-speech. This policy describes what data the extension accesses and how it is used.

Data We Do Not Collect

This extension does not collect, store, transmit, or sell any personal information. No usage analytics, no crash reports, no telemetry is sent to any server operated by this extension.

Local Storage

The extension stores your preferences (voice selection, reading speed, dark mode, read mode, API keys you enter) locally in Chrome's chrome.storage.local. This data never leaves your browser.

Third-Party Services

When you use certain features, the extension communicates with third-party APIs:

  • Google Translate API (translate.googleapis.com) — used for automatic VN→EN sentence translation in bilingual mode. Text of the sentences currently being read is sent to Google's servers. Google's Privacy Policy applies.
  • Google Gemini API (generativelanguage.googleapis.com) — optionally used for translation if you configure a Gemini API key in settings. Text is sent to Google's servers using your own API key. Google's Privacy Policy applies.
  • Browser built-in TTS — speech synthesis runs entirely on-device via Chrome's Web Speech API. No data is sent externally.

Host Permissions

The extension requests optional access to http://*/ and https://*/ solely to read the text content of web pages the user explicitly activates the extension on. No page content is stored or transmitted beyond the TTS/translation services described above.

Permissions Summary

  • activeTab — read text from the current tab when you click the extension button.
  • storage — save your settings locally.
  • scripting — inject content scripts to extract page text.
  • tts / ttsEngine — use Chrome's built-in TTS and support offline Piper voices.
  • alarms — keep the service worker alive during playback.
  • contextMenus — add a right-click "Read Aloud" menu option.
  • offscreen — play audio in the background.
