Read Aloud — Bilingual

Extension đọc truyện online với chế độ song ngữ Việt–Anh.

Chrome Extension

Chưa publish lên Chrome Web Store. Cài đặt thủ công (Load unpacked):

  1. Clone repo hoặc download ZIP từ GitHub
  2. Mở chrome://extensions
  3. Bật Developer mode
  4. Chọn Load unpacked → trỏ vào thư mục đã clone

Tính năng

  • Gốc+EN: đọc từng câu VN → dịch và đọc EN → câu tiếp theo
  • Gốc: chỉ đọc bản gốc, highlight từng câu, không dịch
  • Tự động chuyển chương
  • Hỗ trợ webnovel.vn (chương miễn phí & trả phí)
  • Dark mode, tăng/giảm font size
