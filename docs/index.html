Read Aloud — Bilingual

Chrome extension for reading Vietnamese web novels with bilingual VN–EN mode.

Chrome Extension

Not yet published on the Chrome Web Store. Install manually (Load unpacked):

  1. Clone or download ZIP from GitHub
  2. Open chrome://extensions
  3. Enable Developer mode
  4. Click Load unpacked and select the cloned folder

Features

  • Original+EN: reads each VN sentence → translates and reads EN → next sentence
  • Original: reads source text only, highlights each sentence, no translation
  • Auto-advance to next chapter
  • Supports webnovel.vn (free & paid chapters)
  • Dark mode, adjustable font size
